# SHOTOKAN meta docs

Written findings from the SHOTOKAN replay database: what separates players who win sets from players who don't, across every reviewed set.

| File | What it is |
|---|---|
| [sf6-meta-description.md](sf6-meta-description.md) | Profile of a consistent winner (archetype, spectra, habits) and what the data says so far, with the numbers behind each claim. |
| [observations/](observations) | Dated notes (obs-0001 onward) on what the data shows and how the model changed. A note that stops holding is revised by a newer note, not rewritten. The site's Observations page shows the same notes. |

The numbers come from `sf6.db`, built by the review tools in [shotokan-sf6/tools](https://github.com/shotokan-sf6/tools). The site at [shotokan-sf6/web](https://github.com/shotokan-sf6/web) shows the same findings on its traits page.
